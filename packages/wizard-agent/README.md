# @casebook/wizard-agent

This package will host the authoring wizard agent, built on the [`deepagents`](https://www.npmjs.com/package/deepagents) npm package (the TypeScript port of LangChain Deep Agents) running on Claude.
The agent will turn source material such as spreadsheets into draft process definitions; see [ADR 0011](../../docs/decisions/0011-v1-wizard.md) and [ADR 0012](../../docs/decisions/0012-stack.md).

It is an empty placeholder for now: the `deepagents` dependency and the agent implementation are not added yet.
